# Competitor research — pt-BR / iter-01

Pesquisa feita em 2026-05-23 via App Store Brasil + iTunes Lookup API.

## Categorização do nicho

O nicho "controle de gastos pessoais" no Brasil tem **três clusters** claros competindo pelo mesmo público:

- **Cluster A — Premium banco-conectado** (Open Finance + cartões automático): **Mobills**, **Minhas Economias**, **Organizze**, **Despezzas**, **Pierre**. Estes apps capturam o usuário que aceita conectar a conta bancária pra ter automação.
- **Cluster B — Simples sem-banco** (registro manual, offline-first, "sem assinatura"): **MoneyNote (Controle de Contas e Despesas)**, **Fleur**, **Meu Orçamento**, **Gastos Diários**. Estes apps capturam o usuário que NÃO quer conectar banco — preocupações com privacidade, simplicidade, gratuidade.
- **Cluster C — Nicho B2B/PME**: **Controlle MEI**, **Pierre** (parcial). Não competimos aqui.

**Minhas Despesas (App ID 6502218501)** é Cluster B puro — sem Open Finance, focado em registro manual simples, free. **Concorrentes diretos são Cluster B. Mobills/Despezzas são referência de positioning mas servem público diferente.**

## Insights cross-competitor (síntese)

### Vocabulário canônico do nicho (aparece em ≥3 competitors)

- **Head**: `controle`, `gastos`, `despesas`, `orçamento`, `finanças pessoais`, `financeiro`, `dinheiro`, `economizar`
- **Modificadores comuns**: `mensal`, `pessoal`, `simples`, `fácil`, `rápido`, `automático`, `personalizado`
- **Features universais**: `categorias`, `receitas e despesas`, `gráficos`, `relatórios`, `orçamento mensal`, `transações`
- **Cluster B exclusivo (sem banco)**: `sem cadastro`, `offline`, `widgets`, `Face ID`, `Touch ID`, `iCloud`, `CSV`, `PDF`, `calculadora`, `calendário`
- **Cluster A exclusivo (banco-conectado)**: `Open Finance`, `cartões de crédito`, `bancos`, `Pix`, `extrato`, `dashboard`

### Termos que NOSSO app NÃO usa mas competitors-Cluster-B usam fortemente

| Termo                | Frequência cross-comp | Por quê devemos considerar |
|----------------------|-----------------------|---------------------------|
| `receitas`           | 5/6 competitors       | Par universal "receitas e despesas" — keyword high-volume, low-comp pro nosso nicho |
| `orçamento mensal`   | 4/6                   | Long-tail high-intent — "orçamento" sozinho está nosso, "mensal" multiplica matches |
| `cartões`/`cartão`   | 4/6                   | Mesmo sendo Cluster B, app pode trackear cartões manualmente |
| `Pix` / `transferência` | 0/6 explícito       | **OPORTUNIDADE** — termo brasileiro forte, sub-explorado |
| `rastreador`         | 1/6                   | Variante de "controle" — vale testar como modificador |
| `transações`         | 3/6                   | Sinônimo neutro de "lançamentos"/"registros" |
| `widgets`            | 2/6 (MoneyNote+Fleur) | Feature differentiator se o app tiver |
| `família` / `casal`  | 0/6 explícito         | **OPORTUNIDADE** — target persona sub-explorado |

### Padrão estrutural de Name (heurística pro nosso name 30/30)

- `[Brand] - [head keyword phrase]` → Mobills, Despezzas, Fleur, Pierre
- `Minhas X` / `Meu X` → Minhas Economias, Meu Orçamento, Minhas Despesas (nosso)
- `Controle de X` (puro head-keyword) → Controle de Contas e Despesas (MoneyNote), Controle de Gastos (Fleur)

Nosso name `Minhas Despesas Gastos Contas` (29 chars) é estilo **híbrido brand+keyword** — economiza chars vs `Minhas Despesas - Controle de Gastos` mas perde a frase indexável "controle de gastos". **Não tocaremos no name nesta iter.**

### Padrão de Subtitle observado

- Competitors usam subtitle pra adicionar 1-2 keywords complementares ao name, NÃO pra refrasear.
- Exemplos:
  - MoneyNote name: `Controle de Contas e Despesas` → subtitle (não confirmada via API) provavelmente cobre `orçamento mensal` / `gratuito sem cadastro`.
  - Fleur name: `Controle de Gastos - Fleur` → subtitle provavelmente cobre `orçamento simples` / `sem registro`.
- **Lição**: nosso subtitle `Controle financeiro de despesa` desperdiça chars repetindo "despesa" que já está no name. **Subtitle deve cobrir terms FORA do name** — ex: `Orçamento mensal e finanças` (27/30) ou `Orçamento, contas e receitas` (28/30) — DEFINIR após Astro.

### Riscos competitivos identificados

1. **MoneyNote (Controle de Contas e Despesas)** é o concorrente mais alinhado — mesmo cluster, mesma estrutura de name, 22k reviews, 4.92★. Não vamos ganhar em volume bruto curto-prazo, mas podemos roubar long-tail.
2. **Fleur** está em crescimento (4.86★ com 4.4k reviews, lançado 2022) e ocupa o angle "simples e bonito" — se o nosso app for visual, podemos competir nesse angle no subtitle/promotional_text.
3. **Despezzas** é o mais novo (2023) e tem trajetória de Cluster A — risco baixo pra nosso Cluster B.
